# PetLar — Portal de Adoção de Animais

Interface baseada no projeto `raxadinha`, mantendo seus componentes, estilos e estrutura. Os textos e exemplos foram adaptados ao tema de adoção de animais.

Assim como na referência, o cadastro, a edição e a listagem pública apresentam apenas a estrutura inicial. A página inicial e os detalhes usam dados fixos de demonstração.

```bash
npm start
npm run build
```
